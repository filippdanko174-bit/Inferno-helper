🔥 Inferno Helper

Административный помощник для SA-MP (MoonLoader). Автор: ByFilipp

Скачать для ПК Скачать для Android

Установка
Файл — в moonloader, библиотеки — в moonloader/lib. В игре: /helper.
Возможности
  • Автоматические раздачи: /razd, /razdlast
  • МП, наборы, отборы
  • Сокращения наказаний, умный репорт /arep
  • Шпаргалки следящих
  • Свой биндер: окно /hbinder
Биндер
/bnd add имя /a ку ;; /a второй — создаёт команду /имя. Строки с / уходят как команды, остальные — в чат. Подстановки: {id}, {arg}.
