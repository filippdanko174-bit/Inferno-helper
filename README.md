# 🔥 Inferno Helper

Административный помощник для SA-MP (MoonLoader) — проект **Inferno Pride**.
Автор: **ByFilipp**

## Установка
1. Положите `InfernoHelper.lua` в папку `moonloader`.
2. Библиотеки (`imgui.lua`, `MoonImGui.dll`, `rkeys.lua`, `fAwesome5.lua`) — в `moonloader/lib`, если их ещё нет.
3. В игре: `/helper` — главное меню, `/about` — информация.

> Файл должен оставаться в кодировке **Windows-1251**. Не пересохраняйте его в UTF-8.

## Android (MonetLoader)
Для мобильной версии используйте `InfernoHelper_Mobile.lua` (кодировка **UTF-8**, перекодировка в CP1251 делается автоматически через библиотеку `encoding`). Положите файл в папку скриптов MonetLoader. На ПК используйте `InfernoHelper.lua`.

## Возможности
- **Раздачи призов** — `/razdintro`, `/razd [Фраза] - [Приз]`, `/razdlast [Фраза] - [Приз]` (финальный раунд сам закрывает раздачу). Победитель определяется автоматически, приз выдаётся через `/setstat`.
- **Мероприятия** — `/mphelp` (светофор, поливалка, дерби, прятки и др.).
- **Наборы и отборы** — `/nmenu`, `/omenu`.
- **Модераторские сокращения** — `/amenu`: `/jl`, `/mt`, `/wn`, `/bn`, `/ujl`, `/um`, `/uwn`, `/ubn` и др.
- **Умный репорт** — `/arep [ID]`.
- **Шпаргалки следящих** — `/ldhelp`, `/captlist`, `/bizwarlist`, `/voprmenu`, `/fastlead`.
- **Свой биндер** — окно `/hbinder`, справка `/binder`.

## Биндер
Создавайте свои команды прямо в игре. Откройте окно `/hbinder` или используйте команды:

| Команда | Что делает |
|---|---|
| `/bnd add имя текст` | создать бинд / добавить строку (несколько строк — через `;;`) |
| `/bnd rm имя N` | удалить строку N |
| `/bnd del имя` | удалить бинд |
| `/bnd delay имя мс` | пауза между строками (300–10000) |
| `/bnd show имя`, `/bnd list` | просмотр |

Строка, начинающаяся с `/`, отправляется как команда (`/a ку` → в админ-чат), остальное — в обычный чат.
Подстановки: `{id}` — ID из команды или из `/re`, `{arg}` — текст после команды.
Бинды хранятся в `moonloader/config/InfernoBinder.txt`.

## Надёжность
Все команды и обработчики защищены от ошибок, длинные строки обрезаются, бинды не могут зациклиться.
Если что-то пошло не так — приложите `moonloader/moonloader.log` к Issue.
