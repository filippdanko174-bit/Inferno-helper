# FilippHelper

Помощник администратора SA-MP для MoonLoader (ПК) и MonetLoader (Android).
Автор: **ByFilipp** · поддержка: @ByFilipp123

## Версия
- Текущая версия: **v1 release** (значение `VERSION` и первая строка `version.txt`).
- Основа — рабочая версия **1.1**, к ней добавлены биндер и раздел «Норма» (лидеры и админы).
- Файл для ПК (`FilippHelper.lua`) в cp1251, для телефона (`FilippHelper_Mobile.lua`) в UTF-8.
- Автообновления в скрипте нет: новую версию нужно скачать из репозитория и заменить файл.

## Установка
- **ПК:** `FilippHelper.lua` → папка `moonloader`. Файл в кодировке Windows-1251, не пересохраняйте в UTF-8.
- **Android:** `FilippHelper_Mobile.lua` → папка скриптов MonetLoader. Файл в UTF-8.

В игре: `/fh` — окно с меню слева (группы: главное, администрирование, норма, инструменты; внизу — настройки). `/fcmd` — список команд в обычном диалоге. На странице «Главная» — быстрые кнопки и состояние (ID из `/re`, репорты, авто-`/mp`, ход проверки). На странице «Команды» есть поиск.
Если окно `/fh` не открывается, скрипт покажет диалоговое меню с командами.

## Необходимые библиотеки

| Библиотека | Нужна | ПК (MoonLoader) | Android (MonetLoader) | Зачем |
|---|---|---|---|---|
| **SAMP.Lua** (`samp.events`) | обязательно | идёт с MoonLoader | встроена | перехват чата и диалогов, отправка команд |
| **mimgui** | для окна `/fh` | положить в `moonloader/lib` | встроена | окно `/fh` |
| **encoding** | обязательно | в `moonloader/lib` | встроена | перекодировка UTF-8 ↔ Windows-1251 |
| **ffi** | для окна `/fh` | встроена в LuaJIT | встроена | буферы полей ввода |
| **effil** + **requests** | только для ИИ-ответов (лучший вариант) | в `moonloader/lib` | если есть в загрузчике | запрос к API в отдельном потоке, игра не зависает |
| **ssl.https** + **ltn12** | запасной вариант для ИИ | необязательно | необязательно | если effil/requests нет; запрос блокирует игру на время ответа |
| **curl** | запасной вариант для ИИ | необязательно | если есть `io.popen` и curl | последний запасной способ |

Что будет, если чего-то нет:
- нет **mimgui** или шрифта с кириллицей — `/fh` откроется обычным диалогом со списком команд;
- нет **effil**/**requests** — скрипт пробует `ssl.https`, затем curl; если ничего нет, не работает только «ИИ ответ», а `/aidiag` покажет, чего не хватает;
- нет **encoding** — русский текст будет отображаться неверно.

Ошибки пишутся в `moonloader.log`. Шрифт с кириллицей для окна берётся из системных шрифтов (Windows: папка `Fonts`; Android: `Roboto`).

## Возможности

**Главное и репорты**
- **Репорты** — `/reports` (последние 15, быстрый ответ), `/rr [ID] текст` (ответ через `/pm`), `/ar ID` (ответ и текст жалобы в `/a`).
- **Шаблоны ответов** — `/tpl`, `/rt [ID] N`; в окне — кнопки шаблонов.
- **ИИ-подсказка** — `/ai [ID]` кладёт черновик ответа в строку ввода как `/rr ID текст`; кнопка «ИИ ответ» на странице «Репорты» подставляет черновик в поле. Вы правите и отправляете сами. Настройки — `/aiset url|key|model|prompt значение` или внизу страницы «Настройки». Подходит любой сервис с OpenAI-совместимым API (`chat/completions`). Адрес вида `https://хост/v1` дополняется до `/v1/chat/completions` автоматически. Ключ хранится только в `moonloader/config/FilippHelper_settings.txt` — не выкладывайте этот файл.
- **Уведомление о репорте** — новый репорт выводится в чат (имя, ID, текст).
- **Наказания и сокращения** — `/jj /mut /ww [ID]` (jail, mute, warn), `/bb /uw /uj /unm /ub` (ban, unwarn, unjail, unmute, unban), `/ib /ip /bip /ofl /mkl` (iban, pgetip, banip, offleader, makeleader).

**Раздачи и мероприятия**
- **Раздача призов** — `/gw слово | приз`, финал `/gwlast`, отмена `/gwstop`. Приз: тип и число (`банк 500000`, `лвл 3`, `#9 15`). Победитель определяется по репорту, приз выдаётся автоматически; если тип не распознан — скрипт попросит выдать вручную. Вступление к раздаче: `/razdintro [приз]`.
- **Мероприятия** — `/ev [ключ] [ID] [приз]`, список `/ev`. Готовые анонсы в `/aad`, приз указывается отдельно (`/ev svet 5кк`; для «Догони Инфернус» сначала ID ведущего: `/ev infern 55 5кк`). Окно: `/fh` → «Мероприятия», поле «Приз».
- **Занять задачу** — `/z [ключ]`: три раза «z ...» в `/a`. Авто-`/mp` после отбора в `/aad` и `/o`.
- **Авто-/mp** — после анонса МП и отборов скрипт вводит `/mp` и нажимает первую строку списка (`/mpa` — вручную, `/fhset automp on|off`).

**Фракции и проверка**
- **Фракции** — `/fr` (наборы, отборы), `/nab`, `/otb`, `/otbo`, `/tlead`: наборы, отборы на лидера, временные лидерки. Страница «Фракции» в `/fh`.
- **Проверка активности** — страница «Проверка» в `/fh`: наборы должностей (Руководство, Следящие, ГА и ЗГА, Главные следящие, ЗГС, ПГС, Все), выбор вручную, слово ответа и таймер. Скрипт собирает, кто ответил в `/a`, и показывает список со временем ответа. Команды: `/a1`, `/chk` (окно выбора), `/a1 ио зо gsm t=60 w=слово`, `/chkres` (кто отметился), `/chkend` (закончить и объявить итог в `/a`).
- **Статистика и инвентарь** — `/gs [ID]` (getstats), `/inv [ID]` (checkinv); ID можно брать из `/re`.

**Норма (страница «Норма»)**
- **Лидеры** — список из `/aleaders` и онлайн из `/leaders`. У каждого лидера есть кнопка «Снять» (`/offleader ник`), выполняется после подтверждения «Точно?» в течение 5 секунд.
- **Следящие** — список добавляется вставкой нлиста из ВК (берутся только ник и должность). Проверка каждого через `/getoffstats ник`: норма считается по строке ответа, где есть заданное слово (по умолчанию «онлайн»), и числу после него. Ответ сохраняется в `moonloader/config/FilippHelper_getoffstats_raw.txt`.
- **Нормы** — минимум онлайна для лидеров по структурам (гетто, мафии, госс) и для следящих; задаются в блоке «Настройки нормы и список следящих».
- **Отчёт** — «Обновить всё» (или `/normall`) обновляет лидеров и проверяет следящих. Отчёт выбирается по структуре (Все, Гетто, Мафии, Госс) и формату («Структуры», «Для форума», «Простой список») и копируется в буфер или сохраняется в `moonloader/config/FilippHelper_norm.txt`.
- **Ведущие** — кнопка «Ведущие» собирает отчёт по администрации (красная, ведущая, главные следящие) в виде «норма дд.мм» с эмодзи; должности берутся из нлиста (Куратор сервера, Заместитель КС, ГА, ЗГА, GS Ghetto/Goss/Mafia). Кнопка «Госс (ТД)» — государственные структуры.
- **О скрипте** — блок внизу страницы «Настройки»: версия и разработчики.
- Команды: `/lds` (открыть страницу), `/ldrefresh` (обновить лидеров), `/ldnorm [ghetto|mafia|gov|all] [list]` (отчёт в файл), `/admnorm` (открыть страницу следящих), `/admcheck [ник]` (проверить одного следящего или всех).

**Объявления и памятки**
- **Объявления** — `/pravila` (нормы онлайна и час пик лидерам), `/inf` и `/timeinfo` (инфо и акция за онлайн), `/captlist`, `/bizwarlist` (правила каптов и бизваров), `/razdintro`. Страница «Памятки» в `/fh`.
- **Вопросы лидерам** — `/vopros 1-7` (ответ на частый вопрос).

**Транспорт**
- `/spc` (спавн каров сервера), `/dva` (удаление админ-каров), `/dvs` (удаление и спавн), `/fc` (заправка каров), `/fuel`. Удаление админ-каров всегда идёт с предупреждением в `/a` и таймером 15 секунд; отмена — `/vrstop`. Страница «Транспорт» в `/fh`.

**Прочее**
- `/poll` (опрос), `/notes` (свои шпаргалки), `/gh`, `/wh`, `/gzc`, `/bp` (сокращения команд с ID).
- **Настройки окна** — цвет акцента и фона, прозрачность, готовые цвета (страница «Настройки»).

## Биндер
Окно `/fbind`, команды `/bnd`, справка `/binder`. Строка с `/` уходит как команда, остальное — в чат. Подстановки `{id}`, `{arg}`, `{myid}`, `{mynick}`, задержка `{wait(ms)}` (до 30000). Остановка — `/fstop`. Свободные имена: не занятые командами хелпера (например, `/mm`).

| Команда | Действие |
|---|---|
| `/bnd add имя текст` | создать бинд / добавить строку (несколько через `&` или `;;`) |
| `/bnd rm имя N` | удалить строку |
| `/bnd del имя` | удалить бинд |
| `/bnd delay имя мс` | пауза между строками (300–10000) |
| `/bnd show имя`, `/bnd list` | просмотр |

Бинды хранятся в `moonloader/config/FilippHelper_binds.txt`.

## Файлы в папке config
- `FilippHelper_settings.txt` — настройки, включая ключ API.
- `FilippHelper_binds.txt` — бинды.
- `FilippHelper_admins.txt` — список следящих (ник и должность).
- `FilippHelper_adm_cfg.txt`, `FilippHelper_norm_cfg.txt` — нормы и слово для проверки.
- `FilippHelper_norm.txt`, `FilippHelper_adm_norm.txt` — сохранённые отчёты.
- `FilippHelper_leaders_raw.txt`, `FilippHelper_getoffstats_raw.txt` — сырые ответы серверов, если разбор не сработал.

## Надёжность
Команды и обработчики защищены от ошибок, длинные строки обрезаются, бинды не зацикливаются. Между командами серверу хелпер делает паузы, чтобы не словить кулдаун чата. При проблеме приложите `moonloader.log` и нужный файл из `config`.
