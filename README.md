# FilippHelper

Помощник администратора SA-MP для MoonLoader (ПК) и MonetLoader (Android).
Автор: **ByFilipp** · поддержка: @ByFilipp123

## Установка
- **ПК:** `FilippHelper.lua` → папка `moonloader`. Файл в кодировке Windows-1251, не пересохраняйте в UTF-8.
- **Android:** `FilippHelper_Mobile.lua` → папка скриптов MonetLoader. Файл в UTF-8.

В игре: `/fh` — окно с меню слева (группы: главное, администрирование, инструменты; внизу — настройки), `/fcmd` — список команд в обычном диалоге. Страница «Главная» — быстрые кнопки и состояние (ID из `/re`, репорты, авто-`/mp`, ход проверки), на странице «Команды» есть поиск.
Если окно `/fh` не открывается, скрипт сам покажет диалоговое меню с командами.

## Необходимые библиотеки

| Библиотека | Нужна | ПК (MoonLoader) | Android (MonetLoader) | Зачем |
|---|---|---|---|---|
| **SAMP.Lua** (`samp.events`) | обязательно | идёт с MoonLoader | встроена | перехват чата и диалогов, отправка команд |
| **mimgui** | для окна `/fh` | положить в `moonloader/lib` | встроена | окно `/fh` |
| **encoding** | обязательно | в `moonloader/lib` | встроена | перекодировка UTF-8 ↔ Windows-1251 |
| **ffi** | для окна `/fh` | встроена в LuaJIT | встроена | буферы полей ввода |
| **effil** + **requests** | только для ИИ-ответов (лучший вариант) | в `moonloader/lib` | если есть в загрузчике | запрос к API в отдельном потоке, игра не зависает |
| **ssl.https** + **ltn12** | запасной вариант для ИИ | необязательно | необязательно | если effil/requests нет; запрос блокирует игру на время ответа |
| **curl** | запасной вариант для ИИ | необязательно | если есть `io.popen` и curl | последний запасной способ |

Для JSON используются `encodeJson`/`decodeJson` из MoonLoader, а если их нет — встроенный мини-JSON. Команда `/aidiag` показывает, какие библиотеки и способы отправки доступны в вашем загрузчике.

Что будет, если чего-то нет:
- нет **mimgui** или шрифта с кириллицей — `/fh` откроется обычным диалогом со списком команд;
- нет **effil**/**requests** — скрипт пробует `ssl.https`, затем curl; если ничего нет, не работает только «ИИ ответ», а `/aidiag` покажет, чего не хватает;
- нет **encoding** — русский текст будет отображаться неверно.

Ошибки пишутся в `moonloader.log`. Шрифт с кириллицей для окна берётся из системных шрифтов (Windows: папка `Fonts`; Android: `Roboto`).

## Возможности
- **Раздача призов** — `/gw слово | приз`, финал `/gwlast`, отмена `/gwstop`. Приз: тип и число (`банк 500000`, `лвл 3`, `#9 15`). Победитель определяется по репорту, приз выдаётся автоматически; если тип не распознан — скрипт попросит выдать вручную. Вступление к раздаче: `/razdintro [приз]`.
- **Репорты** — `/reports` (последние 15, быстрый ответ), `/rr [ID] текст`, `/ar ID` (ответ + текст жалобы в `/a`). Шаблоны ответов: `/tpl`, `/rt [ID] N`, в окне — кнопки шаблонов.
- **ИИ-подсказка ответа на репорт** — кнопка «ИИ ответ» на странице «Репорты» подставляет черновик в поле ответа, вы правите и отправляете сами. Команда `/ai [ID]` кладёт ответ в строку ввода как `/rr ID текст`. Настройки — внизу страницы «Настройки» в `/fh`: адрес API, ключ, модель и инструкция с правилами вашего сервера (то же командой `/aiset url|key|model|prompt значение`). Подходит любой сервис с OpenAI-совместимым API (`chat/completions`). Адрес вида `https://хост/v1` дополняется до `/v1/chat/completions` автоматически. Пример для GridAPI: адрес `https://keys.gridapi.ru/v1`, свой ключ, модель `claude-haiku-4-5`. Ключ хранится только в `moonloader/config/FilippHelper_settings.txt` — не выкладывайте этот файл и не публикуйте ключ.
- **Мероприятия** — `/ev [ключ] [ID] [приз]`, список `/ev`. 16 готовых анонсов в `/aad`, приз указывается отдельно (`/ev svet 5кк`, для «Догони Инфернус» сначала ID ведущего: `/ev infern 55 5кк`). Окно: `/fh` → «Мероприятия», поле «Приз».
- **Фракции** — `/fr`, `/nab`, `/otb`, `/otbo`, `/tlead`: наборы, отборы на лидера, временные лидерки.
- **Занять задачу** — `/z ключ`: 3 раза «z ...» в `/a` (`ao`, `oo`, `am`, `ar`, `sp`, `on` или свой текст). Авто-`/mp` после отбора в `/aad` и `/o`.
- **Авто-/mp** — после анонса МП и отборов скрипт вводит `/mp` и нажимает первую строку списка (`/mpa` — вручную, `/fhset automp on|off`).
- **Транспорт** — `/spc` (спавн каров сервера), `/dva` (удаление админ-каров), `/dvs` (удаление и спавн), `/fc` (заправка каров). Удаление админ-каров всегда идёт с предупреждением в `/a` и таймером 15 секунд; отмена — `/vrstop`. Страница «Транспорт» в `/fh`.
- **Проверка активности** — страница «Проверка» в `/fh`: наборы должностей (Руководство, Следящие, ГА и ЗГА, Главные следящие, ЗГС, ПГС, Все; ГС/ЗГС/ПГС — отдельно для госс, гетто и мафий), выбор вручную, слово ответа и таймер, предпросмотр сообщения. Скрипт сам собирает, кто ответил в `/a`, и показывает список с временем ответа. Команды: `/a1`, `/chk` (окно выбора), `/a1 ио зо gsm t=60 w=слово`, `/chkres` (кто отметился), `/chkend` (закончить и объявить итог в `/a`). В чат должности пишутся расшифровкой («И.О. Основателя» и т. д.).
- **Объявления и памятки** — `/pravila` (нормы онлайна и час пик лидерам), `/inf` (инфо игрокам), `/timeinfo` (акция за онлайн), `/captlist`, `/bizwarlist` (правила каптов и бизваров), `/vopros 1-7` (ответ на частый вопрос лидеру). Страница «Памятки» в `/fh`.
- **Наказания и сокращения** — `/jj /mut /ww /bb /uw /uj /unm /ub /ib /ip /bip /ofl /mkl /gzc /gs /inv /bp /wh /gh`.
- **Прочее** — `/poll` (опрос), `/notes` (свои шпаргалки).
- **Анимация открытия** `/fh` — вращающаяся искра, печатающееся название и надпись «by ByFilipp & Claude» (~2 секунды, пропуск по клику). Отключается в «Настройки» → «Анимация открытия окна».
- **Уведомление о загрузке** — при запуске в чат выводится баннер (версия, автор ByFilipp, «при участии Claude», подсказки по меню), а справа сверху на 6 секунд появляется всплывающая карточка. Отключается вместе с анимацией открытия.
- **Метка разработчика** — у ника `Filipp_Evans` в чате добавляется «[Крутой разраб скрипта]» (видна только на вашем экране, отключается в настройках).
- **Лёгкий режим** — «Настройки» → «Лёгкий режим»: без бликов и прозрачности окна, заметно меньше нагрузка. На Android включён по умолчанию.
- **Настройки окна** — стиль Liquid Glass (стекло), цвет акцента и фона, прозрачность, готовые цвета (страница «Настройки» в `/fh`, внизу меню).
- **Биндер** — окно `/fbind`, команды `/bnd`, справка `/binder`. Строка с `/` уходит как команда, остальное в чат. Подстановки `{id}`, `{arg}`. Свободные имена: `/mm` и другие, не занятые командами хелпера.

## Биндер
| Команда | Действие |
|---|---|
| `/bnd add имя текст` | создать бинд / добавить строку (несколько через `;;`) |
| `/bnd rm имя N` | удалить строку |
| `/bnd del имя` | удалить бинд |
| `/bnd delay имя мс` | пауза между строками (300–10000) |
| `/bnd show имя`, `/bnd list` | просмотр |

Бинды хранятся в `moonloader/config/FilippHelper_binds.txt`.

## Надёжность
Команды и обработчики защищены от ошибок, длинные строки обрезаются, бинды не зацикливаются. При проблеме приложите `moonloader.log`.
