# FilippHelper

Помощник администратора SA-MP для MoonLoader (ПК) и MonetLoader (Android).
Автор: **ByFilipp** · поддержка: @ByFilipp123

## Установка
- **ПК:** `FilippHelper.lua` → папка `moonloader` (файл в кодировке Windows-1251, не пересохраняйте в UTF-8).
- **Android:** `FilippHelper_Mobile.lua` → папка скриптов MonetLoader (UTF-8, нужна библиотека `encoding`).

В игре: `/fh` — окно с меню слева (mimgui), `/fcmd` — список команд в обычном диалоге.

> Для окна нужен **mimgui** (на ПК — в `moonloader/lib`, в MonetLoader встроен) и библиотека `encoding`. Если их нет, `/fh` откроет обычное диалоговое окно со списком команд.

## Возможности
- **Раздача призов** — `/gw слово | приз`, финал `/gwlast`, отмена `/gwstop`. Приз: тип и число (`банк 500000`, `лвл 3`, `#9 15`). Победитель определяется по репорту, приз выдаётся автоматически; если тип не распознан — скрипт попросит выдать вручную.
- **Репорты** — `/reports` (последние 15, быстрый ответ), `/rr [ID] текст`, шаблоны ответов: `/tpl`, `/rt [ID] N` (в окне — кнопки шаблонов).
- **Мероприятия** — `/ev` (16 готовых анонсов МП в `/aad`).
- **Фракции** — `/fr`, `/nab`, `/otb`, `/otbo`, `/tlead`: наборы, отборы на лидера, временные лидерки.
- **Наказания и сокращения** — `/jj /mm /ww /bb /uw /uj /unm /ub /ib /ip /bip /ofl /mkl /gzc /gs /inv /bp /fuel /gh /wh`.
- **Прочее** — `/ar` (ответ на репорт), `/poll` (опрос), `/vr` (респавн транспорта), `/notes` (свои шпаргалки).
- **Авто-/mp** — после анонса МП скрипт вводит `/mp` и нажимает первую строку списка (`/mpa` — вручную, `/fhset automp on|off`).
- **Настройки окна** — цвет акцента и фона, прозрачность, готовые цвета (страница «Настройки» в `/fh`).
- **Биндер** — окно `/fbind`, команды `/bnd`, справка `/binder`. Строка с `/` уходит как команда, остальное в чат. Подстановки `{id}`, `{arg}`.

## Биндер
| Команда | Действие |
|---|---|
| `/bnd add имя текст` | создать бинд / добавить строку (несколько через `;;`) |
| `/bnd rm имя N` | удалить строку |
| `/bnd del имя` | удалить бинд |
| `/bnd delay имя мс` | пауза между строками (300–10000) |
| `/bnd show имя`, `/bnd list` | просмотр |

Бинды хранятся в `moonloader/config/FilippHelper_binds.txt`.

## Надёжность
Команды и обработчики защищены от ошибок, длинные строки обрезаются, бинды не зацикливаются. При проблеме приложите `moonloader.log`.
